# Submitting your work

One folder per team, one pull request per team.

1. Fork this repo.
2. Add your work under `submissions/<your-team-name>/`, including `verdict.json` (see `team_handout.md`
   for the format) and the code that produced it.
3. Open a pull request back to this repo. The PR's creation time is your submission time — nothing
   to coordinate with organisers beforehand.

Don't edit anyone else's folder. Keep pushing to your own branch/PR until the freeze; after that,
no more commits will be merged.
